The copied collection already contains Codex adaptations. This PR additionally changes the Playwright entrypoint/reference paths to use repository-local resources, gates shadcn behind explicit project adoption, and adjusts the web-craft router to the skills actually bundled here. Broken relative reference links were corrected, the optional unbundled arena reference was made self-contained, and trailing whitespace in copied helpers/references and excess final blank lines were normalized. Original upstream snapshots remain unchanged. Manifest `installed_skill_sha256` values describe the pre-PR local input copies; they are not checksums of the adapted repository output.

No font binaries, external photos, model weights, personal runtime data or Python/Node dependency installations are included. Reference URLs and library examples do not convey rights to external media or grant access to services.
