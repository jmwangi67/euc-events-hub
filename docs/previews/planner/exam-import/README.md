## Validation

- `npm run format:check`, explicit formatting checks for changed Markdown, ESLint, TypeScript and `git diff --check`: passed.
- Unit suite: **393 passed in 27 files**, including invented bulk JSON/CSV, DST, canonical reconciliation, unchanged preparation mathematics and private-path/build-audit regressions.
- Development Chromium suite: **10 passed** using only the invented dataset. Screenshots above were generated by this run.
- The supplied private archive was independently exercised locally with its reviewed Python sanity validator and the TypeScript JSON/CSV/normalized import paths: **84 canonical occurrences, 32 courses, 98 reported date options, one additional possible date, zero malformed/conflicting records**. Re-import produces identical normalized output. All 84 retain unknown sections/unreviewed audience mappings and remain numerically ineligible. Validation is not independent verification or publication permission.
- The actual private local UI was checked without screenshots or traces, including unapproved windows, possible-only dates, default-hour explanation and focus restoration. Real files, diagnostics and development caches remain gitignored.

The full production validation and CI result are reported on PR #5. Production tests deliberately enable the preview flag and still require no review access or review link. The local build audit checks private identity markers and file traces without publishing their values.

An initial concurrent validation run exposed lint scanning the private development cache; private/scratch directories are now excluded. A navigation assertion timed out under that load and passed on the complete isolated rerun. Dynamic guarded filesystem checks also explicitly opt out of production tracing; the final build has no broad project-tracing warnings. Development Strict Mode revealed a queued native-dialog close event after effect replay; the shared dialog now ignores that stale event while reopened. Tests retain their keyboard assertions and existing timeouts.
