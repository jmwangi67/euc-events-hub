- **Accepted:** no verified enrollment/source coverage, live ingestion or fuzzy deduplication. Distinct canonical IDs for one occurrence still require reconciliation. Consistent duplicates retain original source records; conflicting timings are excluded numerically and labeled uncertain.
- **Accepted presentation tradeoff:** short overlapping hourly slots can require internal vertical scrolling for long titles/metadata. Complete clocks, accessible names, details and List remain available; no page-level horizontal scrolling is intended. Review screenshots before accepting this tradeoff.
- **Testing limitation:** automated 200%-equivalent reflow uses a 720×550 CSS viewport at device scale 2 (the reflow of a 1440×1100 desktop at 200%). Native browser-chrome zoom was not manually operated, and no formal WCAG certification is claimed.
- **Deferred by approval gate:** empirical calibration, numerical overall scoring, cross-factor weighting and Smart Scheduling Recommendations. No algorithm or UI for recommendations was implemented.
